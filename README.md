# Simple Calculator

A lightweight calculator built with HTML, CSS, and vanilla JavaScript. No dependencies or build tools are required.

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.

## Features

- Addition, subtraction, multiplication, and division
- Decimal and positive/negative input
- Clear and delete controls
- Keyboard support: digits, `+`, `-`, `*`, `/`, `.`, `Enter`, `Backspace`, and `Escape`
- Responsive layout
